# Atividade em Sala - Dos Requisitos ao Protótipo Inicial

Protótipo em Python, executado pelo terminal, para o aplicativo de estacionamento do campus.
Implementa o RF01 (visualização das vagas disponíveis) e o RF03 (identificação das vagas reservadas).
Os dados são simulados, pois o cliente ainda não definiu o mecanismo real de obtenção das vagas.
Cada requisito possui sua própria função em um arquivo separado do ponto de entrada.
Para executar, tenha Python 3 instalado e rode `python main.py`.
O resultado no terminal demonstra o comportamento dos dois requisitos implementados.
O projeto foi estruturado para permitir um commit específico para cada requisito concluído.
